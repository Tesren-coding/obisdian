HTML stands for HyperText [[Markup]] Language
uses markup to display and annotate the text, images
#### Rules
- always use lowercase and no spacing to name .html file

```html
<!DOCTYPE html>
<html lang="en">
	<head> 
		<meta charset ="UTF-8">
		<title>  My first Wev Page </title>	
		<style>
			/* CSS */ 
			html {
				font-size: 22px
			}
			
			body {
				background-color: #333;
				color: whitesmoke;
			}
	</head>
	<body>
		<h1> Hello World </h1>
	</body>
</html>
```

We usually have the html tag, head and body element.
`<head>` [[Head Element]] store [[meta data]]
`<title>` goes on the tab of the web page
`<h1>` is usually the largest header element
`<p>` is the paragraph element
 `<style>` uses [[CSS]]
 `lang="en` an [[attribute]]
 `<!DOCTYPE html>`
