SimPy is a Python library for [[discrete-event]]. 

- model how real-world system behaves over time
	- When things happen as a sequence of event
	- Instead of waiting 8 real hours, we can just simulate entire event in seconds

Main ideas in SimPy:
- Environment - simulated clock
- Process - something that happens overtime
- Resources - something with limited capacity
- Event - something that happens at a particular time
- Queue - forms when resources is busy
