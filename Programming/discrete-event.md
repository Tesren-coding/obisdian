A **discrete event** is something that happens at a **specific point in simulated time** and changes the state of the system.

For example, in a production line:

- A part **arrives** at 9:00
- A machine **starts processing** at 9:03
- Processing **finishes** at 9:11
- The part **moves to the next station**
- A machine **breaks down** at 10:20

Instead of continuous value:
9:00:00
9:00:01
9:00:02
9:00:03
...
- more useful for monitoring speed, temperature, pressure, vibration
